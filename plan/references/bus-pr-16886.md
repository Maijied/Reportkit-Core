## Workflow

1. **Filter gate** — company, dates ≤6 months, enums
2. **Prepare** — `GET weeks` → parallel `GET data` (concurrency 3)
3. **Secure store** — encrypt; persist if JSON &lt; ~1.5MB
4. **Compose** — Excel / CSV / PDF / Send from stored rows — **no re-query**

## Host upgrade path

When bus adopts packaged ReportKit instead of inline common-report code:

1. Read [UPGRADE.md](../../UPGRADE.md) and [maintenance docs](https://reportkit.lorapok.tech/docs/0.1/maintenance/upgrade-overview).
2. Align Composer versions: `reportkit/core` + `reportkit/laravel-legacy` on the same tag.
3. Run `php artisan reportkit:install --with-config --publish-assets`.
4. Port domain SQL only — keep `ExportReportService` as the `RowSource` owner.
5. Run `ExportReportCornerCaseTest` (29 tests) before merge.
