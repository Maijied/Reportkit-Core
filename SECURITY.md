# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x (beta) | Yes |

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Report privately to:

**Mohammad Maizied Hasan Majumder**  
Email: [mdshuvo40@gmail.com](mailto:mdshuvo40@gmail.com)

Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Affected package paths (e.g. `reportkit-core/`, `reportkit-website/worker/`)
- Your suggested fix, if any

## Response

You should receive an acknowledgment within **5 business days**. We will work
with you on validation, remediation, and coordinated disclosure when appropriate.

## Scope

In scope:

- ReportKit packages in this monorepo
- The public demo API at `reportkit-api.lorapok.tech`
- The documentation site at `reportkit.lorapok.tech`

Out of scope:

- Third-party dependencies (report via upstream projects)
- Host applications that consume ReportKit (e.g. private Shohoz deployments)
