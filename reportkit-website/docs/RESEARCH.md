# ReportKit research alignment

This demo implements the **Prepare → Secure Store → Compose → Send** architecture from the ReportKit research notes. **All seeded data is fictional** — dummy operators, routes, fares, and trip IDs. No real customer, carrier, or production data is used.

## Thesis (Prepare → Secure Store → Compose → Send)

1. **Prepare** — week-chunked reads from each database (indexed `booked_at`, operator keys).
2. **Secure store** — merged rows held in memory; no re-query during pagination/export.
3. **Compose** — dedupe by `trip_id`, sort, slice for DataTables JSON.
4. **Send** — one response; provenance badge on every number.

## Dual-D1 model

| Database | Years | Operator reference | Indexes |
|----------|-------|-------------------|---------|
| `reportkit_live` | 2018 → present | `trips.operator_id` → `operators.id` | `booked_at`, `operator_id`, composite `(booked_at, operator_id)` |
| `reportkit_archive` | 2012 → 2017 | `trips.operator_code` → live `operators.code` (logical cross-DB FK) | `booked_at`, `operator_code`, composite `(booked_at, operator_code)` |

Overlap rows (`trip_id` prefix `X-`) exist in **both** databases to exercise cross-DB dedupe.

## Scale honesty

| Label | Rows | Where |
|-------|------|-------|
| **synthetic** | 50,000,000 virtual | Worker generator (`mode=synthetic`) — 2012 → now, O(1) per page |
| **live** | 500k + 500k (CI `research` scale) | Cloudflare D1 dummy seed |
| **research-full** | 25M + 25M | Local/paid D1 only (`SEED_SCALE=research-full bash scripts/seed-remote.sh`) |

Free-tier D1 cannot physically store 50M rows. The public demo shows **real indexed dual-DB merge** on a dummy sample plus a **labeled 50M synthetic address space**.

## Seed commands

```bash
cd reportkit-website/worker
npm run seed:sql                    # default: 2k + 2k
SEED_SCALE=research npm run seed:sql  # 500k + 500k → seed/batches/
bash scripts/seed-apply-remote.sh   # push to remote D1 (needs wrangler auth)
```

GitHub Actions: **Seed D1 (manual)** workflow, scale `research` (default).

## Dummy catalog

Twenty fictional operators (`OP01` … `OP20`: Northline Transit, Riverway Coaches, …) and hub-style routes (`HUB-A-HUB-B`, …) are defined in `worker/seed/operators.json` and generated by `generate-research-seed.mjs`.
